# Soldered BME680 MicroPython Library

| ![Enviromental & Air Quality Sensor BME680 Breakout](https://soldered.com/cdn/shop/files/333035_featured-photo_aa4c80_09915cbd-77dc-4c53-919b-e71d59e4a165.jpg) |
| :--------------------------------------------------------------------------------------------------------------------------------: |
|                       [Enviromental & Air Quality Sensor BME680 Breakout](https://soldered.com/products/enviromental-air-quality-sensor-bme680-breakout)                        |

This 4-in-1 atmospheric sensor measures temperature (-40°C to 85°C), humidity (0-100%), pressure, and air quality as an IAQ index (0-500), over I2C with dual Qwiic connectors for solder-free integration. Ideal for weather station and indoor air quality projects. Part of the [Qwiic ecosystem](https://soldered.com/collections/qwiic-ecosystem).

## How to install

---

After [**installing the mpremote package**](https://docs.micropython.org/en/latest/reference/mpremote.html), install the library on your board using the following command:

```sh
  mpremote mip install github:SolderedElectronics/Soldered-BME680-MicroPython-Library
```
Or, if you're running a Windows OS:

```sh
  python -m mpremote mip install github:SolderedElectronics/Soldered-BME680-MicroPython-Library
```
